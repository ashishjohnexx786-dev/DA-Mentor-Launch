DECISION RULES
Tool complexity is not graded.
Every material result must trace to definition + source/grain + validation.
Weighted rates must be recomputed from numerators/denominators, not averaged from subgroup rates.
Observational association is not causal proof.
Expected benefit is a hypothesis, not a guaranteed outcome.
Recommendation requires owner + action + scope/timing + success measure + risk/dependency + stop/continue rule.

GATE STATE MACHINE
A clean Gate A pass ends M09.
Gate B requires failed A + saved attempt + Review A + targeted repair + explicit assignment.
Gate C requires failed B + saved attempt + Review B + targeted repair + explicit assignment.
There is no automatic retest progression and no Gate D.
